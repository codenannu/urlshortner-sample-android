1. Scope

This Privacy Policy describes how the Android application Shortener Deep Link Sample (com.infoezeer.urlshortner) (“the App”) handles information when you install or use it.

The App is a demonstration client for CareerWill URL Shortener Android App Links integration. It is not a social network, marketplace, or account-based consumer product.

This policy covers only the Android sample app. Separate CareerWill products, websites, admin consoles, and APIs may have their own notices.

4. Information the App processes

4.1 On device

  • Incoming App Link URL (HTTPS short URL), including host and short-code path segment.
  • Resolved deep-link payload from the Shortener API (e.g. screen, params, campaign metadata), shown for demonstration.
  • Clipboard — only if you tap Copy URL or Copy JSON; not uploaded solely for that action.
  • In-memory UI state while running (cleared on Clear / process end). No persistent user profile store.

4.2 Over the network

When you open a deep link (or retry), the App may call the configured Shortener API over HTTPS:

CallData sentPurpose
GET /api/v1/deep-links/resolve/{code} Short code; optional short-domain host Resolve navigation payload
POST /api/v1/events/app-open linkCode, platform: "android", optional host Optional analytics (only if build flag POST_APP_OPEN is enabled; default off)

The App does not send Google account credentials, MMID client secrets, or passwords.

4.3 Shortener backend (redirect / clicks)

When a short URL is opened (App, browser, or messaging), the Shortener platform may process click / redirect analytics such as short code, timestamp, User-Agent / platform class, referrer, visitor cookie / hashed visitor identifier, and IP processed as a keyed HMAC hash (not stored as raw IP for unique-visitor style metrics).

Uninstalling the App does not by itself delete historical click analytics on Shortener servers. See Account & data deletion.

4.4 Cookies / similar technologies

The Android App itself does not set web cookies. When a short link is opened in a browser, the Shortener redirect service may set a first-party visitor identifier cookie for analytics continuity.

5. How we use information

  • Demonstrate App Links → resolve → payload display.
  • Optionally record an app-open analytics event when explicitly enabled in the build.
  • Improve reliability of deep-link resolution (errors, timeouts).

We do not use App data for advertising, credit scoring, or sale of personal data.

6. Legal bases (where GDPR / similar laws apply)

  • Legitimate interests — operating a technical sample and measuring short-link opens.
  • Contract / requested service — resolving a link you chose to open.
  • Consent — where required for optional analytics or clipboard actions you initiate.

Operators deploying this sample for production brands should confirm legal bases with counsel.

7. Your rights

Depending on applicable law (GDPR, India’s DPDP Act, CCPA/CPRA), you may have rights to access, correct, delete, restrict/object, portability (where applicable), opt out of sale/sharing for cross-context ads (we do not sell App data), and lodge a complaint with a supervisory authority.

Because the App has no user accounts, verification may rely on dates, short codes, and device details. Contact privacy@careerwill.com.

8. Sharing

The App communicates with the configured Shortener API / redirect hosts. We do not sell personal information. Hosting providers (API, databases, CDN) may process technical logs under operator agreements. Google Play / Android may process install and update metadata under Google’s policies.

10. Security

  • HTTPS for API calls; cleartext HTTP disabled in the App manifest.
  • No MMID or API client secrets embedded in the App.
  • Treat deep-link params as untrusted navigation hints, not authorization.

No method of transmission or storage is 100% secure. Report suspected incidents to privacy@careerwill.com.

11. Children’s privacy

The App is not directed to children under 13 (or the equivalent minimum age in your region). We do not knowingly collect personal information from children. Contact us to request deletion where applicable.

12. Your choices

  • Do not open short links in the App.
  • Clear the on-screen payload using the App’s Clear action.
  • Uninstall the App via Android settings.
  • Keep release builds with POST_APP_OPEN=false (default).
  • Request deletion of server-side analytics — see delete account / data.

13. International transfers

API and analytics infrastructure may be hosted in regions chosen by the operator. Where required, appropriate transfer safeguards should be implemented by the operator.

14. Changes

We may update this Policy. The “Last updated” date will change. Material changes for a Play-distributed build should be reflected at the hosted URL used in Play Console (https://urlshortner.crwilladmin.com/privacy). Keep markdown, HTML, and the Next.js /privacy route in sync.
